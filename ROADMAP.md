# Roadmap

Synkinema prioritizes a reliable desktop workflow that works both manually and
through agents. These are directions, not release-date commitments.

## Next priorities

- Improve preview/export parity, canvas manipulation and keyboard accessibility.
- Keep API/MCP documentation and generated client contracts complete as editing
  operations expand; preserve predictable optimistic rollback and revision guards.
- Add render segmentation and explicit cache/disk budgeting for larger projects.
- Improve the existing local transcription, approximate word alignment and voice
  review; explore stronger forced alignment. Imported/generated speech must remain
  editable, with estimated timings clearly identified.
- Add further project interchange, source organization and export inspection tools.

## Later exploration

LUTs, stabilization, richer audio processing, reusable motion templates and more
advanced caption animation. Any model-driven editing should use the same reviewed
operations and inspect real outputs rather than bypassing the project model.

## Outside the current target

Phone-first editing, hosted multi-tenant accounts, real-time multi-user collaboration
and a cloud rendering service. Local desktop correctness comes first.
